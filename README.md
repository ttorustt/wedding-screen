 # Wedding Screen 2.0

Сервис для вывода сообщений гостей на экран свадьбы в реальном времени.

## Три ссылки

- `/guest` — страница гостя. Открывается по QR-коду, гость пишет и отправляет сообщение.
- `/admin` — закрытая панель администратора. Здесь меняется заставка, видны все сообщения и время отправки, можно показать/убрать сообщение или вывести следующее новое.
- `/screen` — полноэкранная страница для телевизора, LED-экрана или проектора.

## Что добавлено в 2.0

- красивый адаптивный интерфейс гостя;
- более премиальная анимация сообщения на большом экране;
- QR-код на гостевую страницу прямо в админке;
- счётчики новых/показанных сообщений;
- фильтры сообщений;
- кнопка «Показать следующее»;
- удаление уже показанных сообщений;
- защита от слишком частой отправки;
- мгновенные обновления через Socket.IO без перезагрузки страниц.

## Локальный запуск

Нужен Node.js 18+.

```bash
npm install
npm start
```

Открой:

- http://localhost:3000/guest
- http://localhost:3000/admin
- http://localhost:3000/screen

Тестовый пароль админки: `wedding2026`.

Перед публикацией обязательно задай свой пароль:

```bash
ADMIN_PASSWORD="ваш-сложный-пароль" npm start
```

## Важно для публикации

Сообщения хранятся в `data/state.json`, фон — в `public/uploads`. Поэтому для мероприятия нужен Node.js-хостинг с постоянным диском (например VPS или сервис с persistent volume). На обычном бессерверном хостинге файловое хранилище потребуется заменить на базу данных/объектное хранилище.

После публикации QR автоматически ведёт на `https://ваш-домен/guest`.
